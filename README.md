## 🏛️ Currently shipping

**[Foundation Global](https://foundation-global.com)** — Verified-human governance on Solana.
Privacy-first identity layer (NFC passport read + zero-knowledge proof of authenticity +
on-device liveness). **Zero PII retention by construction.** Invitation-only pilot on Solana devnet.

### Three pillars on one verified-human identity layer

| | | |
|---|---|---|
| 🗣️ **Your Voice** | community governance | one person, one verified vote |
| 💎 **Your Share** | pooled community funds | one person, one verified share |
| 🛒 **Your Market** | collective purchasing | community-scale leverage |

## 🛠️ Stack signals

- **Identity & ZK**: Self Protocol · Semaphore · iOS App Attest · Secure Enclave · NFC ePassport
